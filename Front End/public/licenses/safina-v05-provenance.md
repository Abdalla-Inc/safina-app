## Lunar surface texture

- Local asset: `public/assets/moon-lroc-2k.jpg`
- Source page: [NASA Scientific Visualization Studio — CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).
- Download: [lroc_color_2k.jpg](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg).
- Downloaded 29 September 2026, unchanged JPEG, 2048 × 1024.
- Requested credit: **NASA's Scientific Visualization Studio**. The source describes color maps adapted from the LROC WAC mosaic; see that page for dataset and creator credits.
- Used as the color map of a 3D sphere. This is a real lunar-data-derived texture, not a claim that the scene reproduces today's observed lunar phase or astronomical positions.
- SHA-256: `f7130a1822681fa7512d7dcfd40db8c10b9ba4f06777910348698260ed7a2170`.

## Original procedural work

The ship geometry, ornament, timber texture, cloth shading, clouds, smoke and light halos are created in code in this workspace. No purchased or third-party ship model was downloaded. The ship uses Three.js and its MIT-licensed Reflector/OrbitControls/geometry utilities. The standalone build serves its lunar texture locally and makes no runtime request to NASA.

## v0.5 original assets

Wood, canvas and metal color/relief/roughness maps are deterministic originals generated by `src/surfaces.js`. The HDR night environment is generated by `src/lighting.js`. Bow spray is a procedural particle effect. No third-party texture packs, paid models or outside artist assets were added.
